айди, ссылка на пользователя-владельца, тип карты, баланс, статус, список карт, т.к аккаунт главная и может несколько карт иметь

айди, ссылка на пользователя-владельца, тип продукта, статус заявки, описание при отказе, сделано в, обновлено в

айди, ссылка на аккаунт, номер карты, тип карты, имя на карте
